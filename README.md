# Your Name website
Static site for Netlify. No build step.
1. Push this folder to a GitHub repo (branch: main).
2. Netlify > Add new site > Import from Git > pick the repo. Publish directory: `.`
3. Site configuration > Identity > Enable. Then Services > Git Gateway > Enable. Invite yourself.
4. Post at yoursite.netlify.app/admin, or edit content/posts.json on GitHub.
Replace "Your Name", email and text across the pages.
